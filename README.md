# ClimaTech — site demo

Peça de portfólio: landing page fictícia para uma empresa de ar-condicionado e
refrigeração em São Paulo (Brasil). HTML, CSS e JavaScript puros, sem
frameworks ou bibliotecas.

Depoimentos marcados como exemplo; fotos da galeria vêm do Unsplash com crédito.

## Rodar localmente

Abra `index.html` direto no navegador, ou sirva a pasta com qualquer servidor
estático (ex.: `npx serve .`).

## Publicar no GitHub Pages

1. Suba esta pasta para um repositório no GitHub.
2. Em Settings → Pages, selecione a branch e a pasta raiz.
3. Os caminhos já são relativos, então funciona sem ajustes.
